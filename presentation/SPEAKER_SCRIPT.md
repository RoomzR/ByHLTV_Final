- Автобота Telegram для демок пока нет — загрузка через ops.  
- Rating — наша аппроксимация 2.1 / 3.0, не “официальная формула HLTV”.  
- Betting — информационный, не букмекерский движок.  
- Платежный шлюз / Steam OAuth — не в текущем контуре.
